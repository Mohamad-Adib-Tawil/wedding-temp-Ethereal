# دعوة زفاف محمد أديب طويل ورزان بطايحي

موقع دعوة زفاف ثابت، جاهز للنشر على GitHub Pages.

عدّل أسماء العروسين، الموعد، تفاصيل القاعة، النصوص، الروابط، والمراجع إلى الأصول في [`site-config.js`](site-config.js). الأصول المحلية موجودة في `assets/` و`media/gallery/`.

تأكيد الحضور يجهّز رسالة واتساب إلى الرقم المحدد في الإعدادات؛ لا تُخزّن بيانات الردود على هذا الموقع الثابت.
